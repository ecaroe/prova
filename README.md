# Prova

Pequeño prototipo en Pygame de un Tetris doble: un jugador arriba con piezas que caen hacia abajo y otro jugador abajo con piezas que caen hacia arriba, con una línea central donde se detienen. Para ejecutarlo:

```bash
python nuevo.py
```

## Controles

**Jugador arriba**
- A/D: mover izquierda/derecha
- S: bajar
- W: rotar

**Jugador abajo**
- ←/→: mover izquierda/derecha
- ↑: subir (hacia la línea central)
- ↓: rotar
